# Echo Spells

**Echo Spells** is a rhythmic, atmospheric spell-casting game built on the Base mainnet. You play as an **Echo Sorcerer**, harnessing the power of arcane echoes to create devastating spells and rhythmic combat sequences.

## 🌟 Game Concept
You cast powerful spells by creating and manipulating magical echoes. Every spell you cast leaves a lingering echo that can be reused, combined, or amplified. Your rhythm, timing, and strategy determine your success.

## ⚔️ Core Mechanics
- **Echo Casting:** Cast a spell to create a visible, lingering echo in the area.
- **Rhythmic Chains:** Tap your previous echoes at the perfect time to trigger multiplier combos.
- **Echo Resonance:** Combine multiple echoes to build hybrid damage spells.
- **Survival:** Build your combo score to survive against the onslaught of arcane challenges!

## 🔗 On-Chain & Web3 Features
- Connected to **Base Mainnet**.
- Score submissions are securely signed and delivered via trustless infrastructure (ERC-8004 principles).
- Completely transparent transaction attribution.

## 🛠 Tech Stack
- Frontend: React 19, Vite, Tailwind CSS, Framer Motion
- Web3: Wagmi, Viem
- Graphics: Custom native Canvas physics engine

## 🚀 Running Locally

1. Install dependencies:
```bash
npm install
```

2. Start the development server (Full-stack API included):
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## 🧠 AI Agent Capabilities
This application includes MCP API endpoints to seamlessly interact with **Echo Spell Orchestrator**, an ERC-8004 compliant intelligent agent capable of command execution and spell orchestration.
